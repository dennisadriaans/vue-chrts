The `ZoomableAreaChart` component is a self-contained SVG area chart with D3 scroll-zoom and pan. The y-axis rescales to the visible window, so dense time series stay legible as you zoom in. New in v3.

::prose-note
Scroll or pinch to zoom, drag to pan. This chart owns its own SVG (no Recharts/vccs dependency), so it renders client-side only.
::

## Basic Usage

::code-group
:::code-preview{icon="i-lucide-eye" label="Preview"}
<BlocksZoomableAreaChartsBasic class="w-full p-4 bg-elevated/50" />
:::
```vue [Basic.vue]
<script lang="ts" setup>
interface Point {
  date: string
  visitors: number
  signups: number
}

const data: Point[] = Array.from({ length: 120 }, (_, i) => {
  const base = 400 + Math.round(160 * Math.sin(i / 9))
  const noise = Math.round(80 * Math.sin(i / 2.3))
  const d = new Date(2024, 0, 1 + i)
  return {
    date: d.toISOString().slice(0, 10),
    visitors: Math.max(80, base + noise),
    signups: Math.max(20, Math.round((base + noise) * 0.28))
  }
})

const categories: Record<string, BulletLegendItemInterface> = {
  visitors: { name: 'Visitors', color: 'var(--color-blue-400)' },
  signups: { name: 'Signups', color: 'var(--color-green-400)' }
}
</script>

<template>
  <ZoomableAreaChart
    :data="data"
    :categories="categories"
    :height="320"
    x-key="date"
    :curve-type="CurveType.MonotoneX"
    :y-num-ticks="5"
  />
</template>
```
::

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | **Required** | Array of data points. |
| `categories` | `Record<string, BulletLegendItemInterface>` | **Required** | Maps each series key to its name and color. |
| `height` | `number` | `300` | Height of the chart in pixels. |
| `xKey` | `keyof T` | `undefined` | Data key used for x-axis labels and tooltip titles. |
| `xFormatter` | `(index: number) => string` | `undefined` | Formats x-axis tick labels. Receives the row index. |
| `yFormatter` | `(value: number) => string` | `undefined` | Formats y-axis tick labels and tooltip values. |
| `tooltipTitleFormatter` | `(row: T) => string \| number` | `undefined` | Custom formatter for tooltip titles. |
| `xLabel` | `string` | `undefined` | Optional label for the x-axis. |
| `yLabel` | `string` | `undefined` | Optional label for the y-axis. |
| `padding` | `{ top: number; right: number; bottom: number; left: number; }` | `undefined` | Per-side chart padding in pixels. |
| `yNumTicks` | `number` | `5` | Desired number of y-axis ticks. |
| `hideArea` | `boolean` | `false` | Hide the area fill, showing only the line. |
| `fillOpacity` | `number` | `0.15` | Area fill opacity. |
| `lineWidth` | `number` | `2` | Line stroke width in pixels. |
| `curveType` | `CurveType` | `CurveType.Linear` | Curve interpolation (CatmullRom, MonotoneX, Step, Linear). |
| `hideXAxis` | `boolean` | `false` | If true, hides the x-axis. |
| `hideYAxis` | `boolean` | `false` | If true, hides the y-axis. |
| `hideLegend` | `boolean` | `false` | If true, hides the legend. |
| `hideTooltip` | `boolean` | `false` | If true, hides the tooltip. |
| `minZoom` | `number` | `1` | Minimum zoom scale (1 = no zoom out). |
| `maxZoom` | `number` | `8` | Maximum zoom scale. |
| `yPaddingFactor` | `number` | `0.08` | Fraction of the visible value span added as breathing room above/below the y-axis domain. |

## Data Format

Each object is one data point. Every key referenced in `categories` is plotted as a series.

```ts [types.ts]
interface ZoomableAreaChartData {
  date: string
  [seriesKey: string]: string | number
}
```
