The `Sparkline` component renders a small, axis-free chart that communicates the shape of a trend in the space of a single line of text. It's ideal for KPI cards, table cells and dense dashboards where a full chart would be too heavy.

## Example

Here's an example showing the `line`, `area` and `bar` variants next to a metric.

```vue [Sparkline.vue]
<script setup lang="ts">
const revenue = [12, 18, 15, 22, 19, 28, 26, 34, 30, 38, 44, 41]
</script>

<template>
  <Sparkline
    :data="revenue"
    type="area"
    color="var(--ui-success)"
    :width="140"
    :height="40"
    show-last-point
  />
</template>
```
```bash [Terminal]
nuxt-charts add Sparkline
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `number[]` | **Required** | The series of numeric values to plot. |
| `type` | `'line' \| 'area' \| 'bar'` | `'line'` | Rendering style of the sparkline. |
| `color` | `string` | `var(--ui-primary)` | Stroke / fill color. Accepts any CSS color or variable. |
| `width` | `number` | `120` | Width of the SVG viewport in pixels. |
| `height` | `number` | `32` | Height of the SVG viewport in pixels. |
| `strokeWidth` | `number` | `2` | Stroke width for the line / area variants. |
| `showArea` | `boolean` | `false` | Fill a gradient below the line (line variant). |
| `showLastPoint` | `boolean` | `false` | Render a marker dot on the last data point. |
| `min` | `number` | data min | Force the lower bound of the value scale. |
| `max` | `number` | data max | Force the upper bound of the value scale. |
