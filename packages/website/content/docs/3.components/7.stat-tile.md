The `StatTile` component is a compact KPI card that pairs a headline metric with a trend delta and an optional inline [Sparkline](/docs/components/sparkline). It's the building block of the top row of almost every analytics dashboard.

## Example

Here's a row of stat tiles tracking a fictional SaaS product.

::code-group
:::code-preview{icon="i-lucide-eye" label="Preview"}

  </DocsExamplesStatTile>

```vue [StatTile.vue]
<script setup lang="ts">
const revenue = [42, 48, 45, 52, 49, 58, 56, 64, 61, 70, 76, 84]
</script>

<template>
  <StatTile
    label="Monthly revenue"
    value="84,120"
    prefix="$"
    icon="i-lucide-dollar-sign"
    :trend="{ value: '+12.5%', direction: 'up' }"
    caption="vs. last month"
    :sparkline="revenue"
    sparkline-type="area"
  />
</template>
```
```bash [Terminal]
nuxt-charts add StatTile
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | **Required** | Metric label, e.g. "Monthly revenue". |
| `value` | `string \| number` | **Required** | The primary value shown in the tile. |
| `prefix` | `string` | — | Rendered before the value, e.g. `$`. |
| `suffix` | `string` | — | Rendered after the value, e.g. `%`. |
| `trend` | `{ value: string, direction: 'up' \| 'down' \| 'neutral' }` | — | Trend / delta badge. Controls color and icon. |
| `caption` | `string` | — | Secondary caption under the trend. |
| `icon` | `string` | — | Optional leading icon (Iconify name). |
| `sparkline` | `number[]` | — | Optional inline sparkline series. |
| `sparklineType` | `'line' \| 'area' \| 'bar'` | `'area'` | Sparkline rendering style. |
| `color` | `string` | trend-aware | Color for the sparkline. |
| `animate` | `boolean` | `false` | Animate the value with a rolling effect. |
