v3 swaps the rendering engine from **Unovis** to [**vccs**](https://vue-charts.com) (an unofficial Vue 3 port of Recharts) while keeping the **config-prop API** you already use — `:data`, `:categories`, `:height`, `:y-axis`, `:curve-type`, and friends. In most projects the upgrade is a dependency swap; your templates keep working.

## What stays the same

- The component names: `AreaChart`, `BarChart`, `LineChart`, `DonutChart`, `BubbleChart`.
- The config-prop API and the auto-imported enums/types (`CurveType`, `LegendPosition`, `Orientation`, `DonutType`, `BulletLegendItemInterface`, `AxisConfig`, `TooltipConfig`, …).
- Auto-imported, client-rendered, SSR-safe components.
- The `DonutChart` center-content default slot (e.g. a `%` label in the middle of the ring).

## What's new

- **New chart types:** [Radar](/docs/charts/radar-chart), [Radial Bar](/docs/charts/radial-bar-chart), [Funnel](/docs/charts/funnel-chart), [Candlestick](/docs/charts/candlestick-chart) and [Status Tracker](/docs/charts/status-tracker-chart).
- **New cross-cutting props** on cartesian charts: `referenceLines`, `syncId`, `xExplicitTicks` / `yExplicitTicks`, and `minMaxTicksOnly`.

## Install

::code-group
```bash [pnpm]
pnpm add nuxt-charts-next
```
```bash [npm]
npm install nuxt-charts-next
```
```bash [yarn]
yarn add nuxt-charts-next
```
::

`vccs` and `motion-v` ship as dependencies of the module — no extra install needed.

## Configure

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  // Replace "nuxt-charts" with "nuxt-charts-next"
  modules: ["nuxt-charts-next"]
})
```

## Running both engines side by side

The v3 engine does not (yet) provide the specialty components — **maps** (`TopoJSONMap`, `DottedMap`), `GanttChart`, `DagreGraph`, `DualChart` and `SankeyChart`. If you use those, keep the v2 module registered for them only, and let v3 own the standard charts. Use `include` so v2 doesn't re-register the shared chart names, and `sharedImports: false` so v3 remains the single source of the shared enums/types:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    "nuxt-charts-next",
    ["nuxt-charts", {
      include: ["GanttChart", "DagreGraph", "DualChart", "SankeyChart", "TopoJSONMap", "DottedMap"],
      sharedImports: false
    }]
  ]
})
```

## Deprecated (inert) props

A handful of Unovis-only props have no vccs analog. They are kept on the type interfaces and marked `@deprecated` so existing templates still type-check without error — they simply have no effect: `crosshairConfig`, and on `BarChart`, `stackAndGrouped` / `stackedGroupedSpacing` (use `stacked`).
