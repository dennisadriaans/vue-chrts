## 1. Install dependencies

Use your preferred package manager to install the library:

::code-group
```bash [Nuxt]
pnpm add nuxt-charts
```
```bash [Vue]
pnpm add vue-chrts @unovis/ts @unovis/vue
```
::

:::prose-warning
**Warning!**
If you're using **pnpm** in a Nuxt project, set `shamefully-hoist=true` in your `.npmrc` to avoid the "to-px" error, or install `@unovis/ts` as a dependency.
:::

:::prose-tip
**New in v3 —** the `nuxt-charts-next` module renders through [vccs](https://vue-charts.com) instead of Unovis, keeps the same config-prop API, and adds Radar, Radial Bar, Funnel, Candlestick, Status Tracker and Zoomable Area charts. See [Upgrade to v3](/docs/getting-started/upgrade-to-v3) for the (mostly drop-in) migration.
:::


## 2. Configuration (Nuxt only)

If you are using Nuxt, add the module to your `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ["nuxt-charts"]
})
```

*For Vue-only projects, no additional configuration is required.*

## 3. Test installation

::code-group
```vue [Nuxt]
<script setup lang="ts">
const data = [
  { month: 'Jan', sales: 100, profit: 50 },
  { month: 'Feb', sales: 120, profit: 55 },
  { month: 'Mar', sales: 180, profit: 80 },
  { month: 'Apr', sales: 110, profit: 40 },
  { month: 'May', sales: 90, profit: 30 },
]

const categories = {
  sales: {
    name: 'Sales',
    color: '#3b82f6',
  },
  profit: {
    name: 'Profit',
    color: '#10b981',
  },
}

const xFormatter = (i: number) => data[i].month
</script>

<template>
  <LineChart
    :data="data"
    :categories="categories"
    :height="300"
    :xFormatter="xFormatter"
    xLabel="Month"
    yLabel="Amount"
  />
</template>
```

```vue [Vue]
<script setup lang="ts">
import { LineChart, LegendPosition } from 'vue-chrts'

const data = [
  { month: 'Jan', sales: 100 },
  { month: 'Feb', sales: 120 },
]

const categories = {
  sales: {
    name: 'Sales',
    color: '#3b82f6'
  }
}
</script>

<template>
  <LineChart
    :data="data"
    :categories="categories"
    :legendPosition="LegendPosition.TopCenter"
  />
</template>
```

## Library Comparison

When searching for the right charting solution, it's important to understand how different libraries stack up.

| Feature | Nuxt Charts | Chart.js | Unovis |
| :--- | :--- | :--- | :--- |
| **Rendering** | SVG (native) | Canvas | SVG (native) |
| **Type Safety** | ✅ Full TypeScript | Partial | ✅ Full TypeScript |
| **Style System** | Tailwind / Nuxt UI | Custom CSS | Framework-agnostic |
| **SEO Ready** | ✅ Yes | ❌ Limited | ✅ Yes |
| **Best For** | Modern Nuxt/Vue Apps | Legacy/Simple Apps | Complex Dashboards |
