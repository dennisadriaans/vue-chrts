## Add Global CSS Variables

v3 charts expose `--vc-*` tokens on the `.vue-chrts` root. Override them globally or per chart:

```css [assets/css/main.css]
.vue-chrts {
  /* Grid + axis */
  --vc-grid-color: var(--ui-border);
  --vc-axis-line-color: var(--ui-border);
  --vc-tick-color: var(--ui-text-muted);
  --vc-axis-label-color: var(--ui-text);

  /* Legend */
  --vc-legend-color: var(--ui-text-muted);
  --vc-legend-gap: 0.75rem;

  /* Tooltip */
  --vc-tooltip-bg: var(--ui-bg-elevated);
  --vc-tooltip-fg: var(--ui-text);
  --vc-tooltip-muted: var(--ui-text-muted);
  --vc-tooltip-border: var(--ui-border);
}

/* Dark mode example: override theme variables */
.dark {
  --custom-primary: oklch(0.72 0.192 149.58);
  --custom-secondary: oklch(0.63 0.1963 157.86);
  /* ...override other variables for dark mode as needed... */
}
```
