Display bars and lines together in one chart. Use this component to compare metrics with different scales—like revenue bars with a growth rate line—or highlight trends alongside categorical data.

## Basic Usage

::code-group
:::code-preview{icon="i-lucide-eye" label="Preview"}
<DocsDualChartBasic class="w-full p-4 bg-elevated/50" />
:::
```vue [Basic.vue]
<script lang="ts" setup>
defineOptions({
  tags: ['dualchart', 'basic']
})

interface ChartItem {
  month: string
  revenue: number
  growth: number
}

const data: ChartItem[] = [
  { month: 'Jan', revenue: 420, growth: 120 },
  { month: 'Feb', revenue: 480, growth: 250 },
  { month: 'Mar', revenue: 510, growth: 380 },
  { month: 'Apr', revenue: 490, growth: 440 },
  { month: 'May', revenue: 550, growth: 520 },
  { month: 'Jun', revenue: 600, growth: 650 }
]

const barCategories: Record<string, BulletLegendItemInterface> = {
  revenue: { name: 'Revenue', color: '#3b82f6' }
}

const lineCategories: Record<string, BulletLegendItemInterface> = {
  growth: { name: 'Growth %', color: '#22c55e' }
}

const xFormatter = (tick: number) => data[tick]?.month ?? ''
</script>

<template>
  <DualChart
    :data="data"
    :height="300"
    :bar-categories="barCategories"
    :line-categories="lineCategories"
    :bar-y-axis="['revenue']"
    :line-y-axis="['growth']"
    :x-formatter="xFormatter"
    :y-grid-line="true"
    :legend-position="LegendPosition.TopRight"
  />
</template>
```
::

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | **Required** | Array of data points. Each element contains values for both bar and line series. |
| `height` | `number` | **Required** | Height of the chart in pixels. |
| `barCategories` | `Record<string, BulletLegendItemInterface>` | **Required** | Bar series configuration: name and color for each data key. |
| `lineCategories` | `Record<string, BulletLegendItemInterface>` | **Required** | Line series configuration: name and color for each data key. |
| `barYAxis` | `(keyof T)[]` | **Required** | Property keys from data to display as bars. |
| `lineYAxis` | `(keyof T)[]` | **Required** | Property keys from data to display as lines. |
| `xLabel` | `string` | `undefined` | Label for the x-axis. |
| `yLabel` | `string` | `undefined` | Label for the primary y-axis (bars). |
| `yLabelSecondary` | `string` | `undefined` | Label for the secondary y-axis (lines). |
| `padding` | `{ top: number; right: number; bottom: number; left: number }` | `undefined` | Chart padding (top, right, bottom, left). |
| `xFormatter` | `axisFormatter` | `undefined` | Formats x-axis labels. `(tick, i, ticks) => string`. |
| `yFormatter` | `axisFormatter` | `undefined` | Formats y-axis labels. `(tick, i, ticks) => string`. |
| `tooltipTitleFormatter` | `(data: T) => string \| number` | `undefined` | Custom formatter for tooltip titles. |
| `curveType` | `CurveType` | `undefined` | Curve interpolation type for lines (see Curve Types). |
| `lineWidth` | `number` | `2` | Width of the line in pixels. |
| `xNumTicks` | `number` | `undefined` | Desired number of ticks on the x-axis. |
| `xExplicitTicks` | `(number \| string \| Date)[]` | `undefined` | Force specific ticks on the x-axis. |
| `minMaxTicksOnly` | `boolean` | `false` | If true, only show first and last ticks on the x-axis. |
| `yNumTicks` | `number` | `undefined` | Desired number of ticks on the y-axis. |
| `hideLegend` | `boolean` | `false` | If true, hides the chart legend. |
| `hideTooltip` | `boolean` | `false` | If true, hides the chart tooltip. |
| `legendPosition` | `LegendPosition` | `undefined` | Position of the legend. |
| `legendStyle` | `string \| Record<string, string>` | `undefined` | Custom CSS style for the legend container. |
| `xDomainLine` | `boolean` | `false` | Show domain line on the x-axis. |
| `yDomainLine` | `boolean` | `false` | Show domain line on the y-axis. |
| `xTickLine` | `boolean` | `false` | Show tick lines on the x-axis. |
| `yTickLine` | `boolean` | `false` | Show tick lines on the y-axis. |
| `xGridLine` | `boolean` | `false` | Show grid lines on the x-axis. |
| `yGridLine` | `boolean` | `false` | Show grid lines on the y-axis. |
| `hideXAxis` | `boolean` | `false` | If true, hides the x-axis. |
| `hideYAxis` | `boolean` | `false` | If true, hides the y-axis. |
| `crosshairConfig` | `CrosshairConfig` | `undefined` | Crosshair configuration for the hover line. |
| `xAxisConfig` | `AxisConfig` | `undefined` | Configuration for x-axis appearance. |
| `yAxisConfig` | `AxisConfig` | `undefined` | Configuration for y-axis appearance. |
| `yDomain` | `[number \| undefined, number \| undefined]` | `undefined` | Domain for the y-axis. |
| `xDomain` | `[number \| undefined, number \| undefined]` | `undefined` | Domain for the x-axis. |
| `stacked` | `boolean` | `false` | If true, stacks the bars. |
| `groupPadding` | `number` | `undefined` | Padding between bar groups in pixels. |
| `barPadding` | `number` | `0.2` | Fractional padding between bars (0-1). |
| `radius` | `number` | `2` | Rounded corners for bars in pixels. |
| `orientation` | `Orientation` | `'vertical'` | Orientation of the bars (vertical or horizontal). |
| `tooltip` | `TooltipConfig` | `undefined` | Tooltip configuration (hideDelay, showDelay, followCursor). |
| `duration` | `number` | `undefined` | Animation duration in milliseconds. |

## Data Format

Provide an array of objects containing values for both bar and line series:

```ts [types.ts]
interface DualChartData {
  month: string       // x-axis label
  revenue: number     // bar value
  growth: number      // line value
}
```

## Categories Format

Define separate categories for bars and lines:

```ts [types.ts]
const barCategories = {
  revenue: { name: 'Revenue', color: '#3b82f6' },
}

const lineCategories = {
  growth: { name: 'Growth %', color: '#22c55e' },
}
```
